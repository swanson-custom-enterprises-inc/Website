💡 ONE SOUND Hints

Edit Mode

Use Edit Mode to add audio, rename cues, choose colors, rearrange cues, and test sounds.

Show Mode

Show Mode is designed for running the show.

The layout is: Next → Current → Previous

The large button in the center is GO.

GO / STOP

When the Current Cue is stopped, the button says GO.

When it is playing, the same button changes to STOP.

Auto Advance

When enabled, finishing a cue automatically selects the next cue.

The next cue does not begin playing by itself. It becomes the new Current Cue and waits for GO.
